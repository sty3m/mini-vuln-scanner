# Security Policy

## Scope

This project is an educational, read-only web reconnaissance scanner. Use it only against systems you own or have explicit authorization to test.

## Reporting a security issue

If you discover a security issue in this project, please report it privately to the repository owner rather than publishing exploit details in a public issue.

When reporting, include:
- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any relevant logs or proof of concept that can be shared safely

Please do not include secrets, credentials, or personal data in reports.

## Responsible use

Do not use this project to scan or test third-party systems without authorization.
